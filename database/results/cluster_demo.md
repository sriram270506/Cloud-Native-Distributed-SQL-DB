Generated by `python database/seed_cluster.py` against a live three-node Raft cluster.

Node `node-1` reports state **Follower**, leader `node-2`, term 2, commit index 7.

## GROUP BY with COUNT and AVG

```sql
SELECT category, COUNT(*) AS products, AVG(unit_price) AS avg_price FROM products GROUP BY category ORDER BY category
```

| category | products | avg_price |
|---|---|---|
| accessories | 2 | 5.99 |
| devices | 2 | 249.99 |
| gadgets | 2 | 12.49 |
| tools | 2 | 54.99 |

## GROUP BY ... HAVING

```sql
SELECT method, COUNT(*) AS payments, SUM(amount) AS total FROM payments GROUP BY method HAVING payments > 1
```

| method | payments | total |
|---|---|---|
| paypal | 2 | 16.98 |
| card | 8 | 929.88 |
